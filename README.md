# ربات فروش کانفیگ v2ray

ربات تلگرامی برای فروش اشتراک v2ray با پنل 3x-ui، سیستم معرفی دوستان (رفرال) و چت ناشناس با پشتیبان.

## امکانات
- 🛒 خرید اشتراک: انتخاب حجم و مدت → کارت‌به‌کارت → ارسال رسید → تأیید ادمین → تحویل فوری لینک
- 🎁 معرفی دوستان: با دعوت ۱۰ نفر، اشتراک رایگان ۵ گیگابایتی (۳۰ روزه) هدیه بگیر
- 💬 چت ناشناس: پیام کاربر به ادمین می‌رسد (با نام و آیدی)؛ ادمین ریپلای می‌کند و پاسخ با نام «پشتیبان» به کاربر می‌رسد

## راه‌اندازی روی لپ‌تاپ
```bash
pip install -r requirements.txt
copy .env.example .env   # مقادیر را پر کن
python bot.py
```

متغیرهای `.env`:
- `BOT_TOKEN` — توکن از [@BotFather](https://t.me/BotFather)
- `ADMIN_ID` — آیدی عددی خودت (از @userinfobot)
- `CARD_NUMBER` / `CARD_HOLDER` — شماره کارت نمایشی
- `XUI_*` — اطلاعات پنل 3x-ui (آدرس، یوزر/پس، شماره اینباند، آدرس سرویس subscription)
- `REFERRAL_TARGET` — حداقل دعوت برای جایزه (پیش‌فرض ۱۰؛ برای تست موقتاً ۲ کن)

## انتقال به سرور یا Railway جدید (Import/Export)
1. در ربات فعلی دستور `/export` بزن → دو فایل می‌گیری: دیتابیس (`bot-db-*.db`) و تنظیمات (`env-*.txt`).
2. روی مقصد، پروژه را کلون/کپی کن، فایل `.env` را از نسخه دانلودشده بساز (در Railway: متغیرها را دستی وارد Variables کن).
3. ربات مقصد را یک بار اجرا کن تا اسکیمای دیتابیس ساخته شود.
4. دستور `/import` را در ربات بزن و فایل `bot-db-*.db` را بفرست؛ بعد از تأیید، داده‌ها (کاربران، سفارش‌ها، رفرال‌ها، پنل‌ها) جایگزین می‌شوند. از داده‌های قبلی هم خودکار پشتیبان گرفته می‌شود.
5. ربات را ری‌استارت کن. تمام.

## دیپلوی روی Railway
1. پروژه را در گیت قرار بده و به Railway وصل کن.
2. یک Volume در مسیر `/data` بساز و متغیر `DATABASE_PATH=/data/bot.db` را ست کن تا داده‌ها بعد از ری‌استارت حفظ شوند.
3. همه متغیرهای `.env.example` را در بخش Variables وارد کن.
4. Railway خودش Dockerfile را می‌بیند و اجرا می‌کند (polling — نیازی به وب‌هوک نیست).

## نکته درباره 3x-ui
در پنل، برای اینباند موردنظر باید Subscription فعال باشد. لینکی که ربات می‌دهد به شکل `{XUI_SUB_BASE_URL}/{subId}` است.
