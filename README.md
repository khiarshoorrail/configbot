# ربات فروش کانفیگ v2ray

ربات تلگرامی کامل برای فروش اشتراک v2ray و پروکسی تلگرام: خرید کارت‌به‌کارت با تأیید ادمین و تحویل فوری لینک، سیستم معرفی دوستان با جایزه خودکار، چت ناشناس با پشتیبان، داشبورد وب ادمین با Bootstrap، پشتیبان خودکار روزانه روی گیت‌هاب.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 🛒 فروش اشتراک | کاربر حجم و مدت را انتخاب می‌کند → شماره کارت را می‌بیند → رسید می‌فرستد → ادمین تأیید می‌کند → لینک اشتراک + راهنمای اتصال فوری |
| 🎁 معرفی دوستان | لینک اختصاصی هر کاربر؛ با رسیدن به `REFERRAL_TARGET` نفر، اشتراک رایگان هدیه خودکار صادر می‌شود |
| 💬 چت ناشناس | پیام کاربر به ادمین می‌رسد (با نام/آیدی/آمار)؛ ادمین روی پیام ریپلای می‌کند و پاسخ با نام «پشتیبان» به کاربر می‌رسد |
| 🌐 وب‌پنل ادمین | آمار و پیام همگانی، لیست کاربران با جستجو، تأیید/رد سفارش از مرورگر، ویرایش پلن‌ها و قیمت‌ها بدون تغییر کد، مدیریت چند پنل 3x-ui/Marzban |
| ☁️ پشتیبان روزانه | هر ۲۴ ساعت دیتابیس به یک ریپوی خصوصی گیت‌هاب آپلود می‌شود (۱۴ نسخه آخر نگه داشته می‌شوند) |
| 🔁 چند-پنلی | توزیع چرخشی سفارش‌ها بین پنل‌های فعال + fallback خودکار اگر پنلی قطع شد |

## 📦 ساختار پروژه

```
bot.py              نقطه ورود (polling تلگرام + وب‌پنل + حلقه بکاپ)
config.py           خواندن تنظیمات از .env
plans.py            seed اولیه پلن‌ها (بعد از آن از دیتابیس خوانده می‌شوند)
database.py         SQLite: users, referrals, orders, panels, plans, settings
services.py         منطق مشترک تأیید/رد سفارش (تلگرام + وب)
panels_api.py       کلاینت‌های 3x-ui و Marzban + round-robin/fallback
github_backup.py    آپلود پشتیبان با GitHub API
handlers/           start, buy, referral, chat, mysubs, panels (تلگرام), backup
admin_web/          سرور aiohttp + قالب‌های Jinja2 (Bootstrap 5 RTL)
```

## 🚀 راه‌اندازی سریع روی لپ‌تاپ

```bash
git clone https://github.com/shadman-real/configbot.git
cd configbot
pip install -r requirements.txt
copy .env.example .env    # ویندوز | در لینوکس: cp
# فایل .env را پر کن (جدول پایین)
python bot.py
```

### متغیرهای `.env` (همه)

| متغیر | اجباری؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID` | ✅ | آیدی عددی خودت (از [@userinfobot](https://t.me/userinfobot)) |
| `CARD_NUMBER` / `CARD_HOLDER` | ✅ | شماره کارت و نام صاحب حساب که به خریدار نمایش داده می‌شود |
| `REFERRAL_TARGET` | — | تعداد دعوت لازم برای جایزه (پیش‌فرض ۱۰) |
| `REFERRAL_REWARD_GB` / `_DAYS` | — | مشخصات اشتراک هدیه (پیش‌فرض ۵ گیگ / ۳۰ روز) |
| `XUI_BASE_URL` / `XUI_USERNAME` / `XUI_PASSWORD` / `XUI_INBOUND_ID` / `XUI_SUB_BASE_URL` | — | فقط بار اول: اگر جدول پنل‌ها خالی باشد، به‌عنوان «پنل پیش‌فرض» وارد می‌شود. بعد از آن مدیریت از `/panels` یا وب‌پنل |
| `PROXY_URL` | — | فقط برای ایران: `socks5://127.0.0.1:10808` (روی Railway **خالی** بگذار) |
| `DATABASE_PATH` | — | مسیر فایل دیتابیس (پیش‌فرض `bot.db`) |
| `GITHUB_BACKUP_REPO` | — | ریپوی خصوصی بکاپ به شکل `username/repo` |
| `GITHUB_TOKEN` | — | [Personal Access Token](https://github.com/settings/tokens) با دسترسی `repo` (Contents: Read and write) |
| `GITHUB_BACKUP_KEEP` | — | تعداد نسخه‌های نگهداری‌شده (پیش‌فرض ۱۴) |
| `ADMIN_WEB_ENABLED` | — | `1` = وب‌پنل روشن |
| `ADMIN_WEB_PASSWORD` | — | رمز ورود وب‌پنل (**اجباری** برای استارت وب‌پنل — قوی انتخاب کن) |
| `ADMIN_WEB_HOST` | — | پیش‌فرض `0.0.0.0` |
| `ADMIN_WEB_PORT` | — | پیش‌فرض `8080` (روی Railway متغیر `PORT` خودکار استفاده می‌شود) |

## 🌐 وب‌پنل ادمین

بعد از اجرا: `http://127.0.0.1:8080` (یا دامنه Railway)

| صفحه | امکانات |
|---|---|
| آمار `/` | تعداد کاربران، فروش امروز/کل، در انتظار تأیید + ارسال پیام همگانی |
| کاربران `/users` | نام، یوزرنیم، آیدی، تعداد دعوت، سفارش‌ها + جستجو |
| سفارش‌ها `/orders` | فیلتر وضعیت + تأیید/رد از مرورگر (کاربر خودکار لینک می‌گیرد) |
| پلن‌ها `/plans` | افزودن/ویرایش/حذف حجم‌ها، مدت‌ها و قیمت‌ها — بدون تغییر کد |
| پنل‌ها `/panels` | افزودن پنل 3x-ui/Marzban با تست اتصال، ویرایش، فعال/غیرفعال، حذف |

امنیت داخلی: ورود با رمز + rate-limit (۵ تلاش ناموفق در ۱۰ دقیقه)، CSRF token روی همه فرم‌ها، کوکی HttpOnly/Secure/SameSite با انقضای ۱۲ ساعت، هدرهای CSP/X-Frame-Options/nosniff، عملیات تغییردهنده فقط POST.

## 🚢 دیپلوی روی Railway (گام‌به‌گام)

1. **Fork یا clone** این ریپو را به حساب گیت‌هاب خودت منتقل کن (اگر از این ریپو استفاده می‌کنی، همان را وصل کن).
2. وارد [railway.com](https://railway.com) شو → **New Project** → **Deploy from GitHub repo** → ریپو را انتخاب کن.
3. بعد از اولین build، روی سرویس → تب **Variables** این‌ها را بساز:

   ```
   BOT_TOKEN=<توکن ربات>
   ADMIN_ID=<آیدی عددی تو>
   CARD_NUMBER=شماره-کارت
   CARD_HOLDER=نام-صاحب-حساب
   REFERRAL_TARGET=10
   ADMIN_WEB_ENABLED=1
   ADMIN_WEB_PASSWORD=<رمز-قوی-وب‌پنل>
   GITHUB_BACKUP_REPO=<username>/<backup-repo>
   GITHUB_TOKEN=<PAT با دسترسی repo>
   DATABASE_PATH=/data/bot.db
   ```

4. تب **Settings** → **Volumes** → **New Volume** → Mount path: `/data` (تا دیتابیس بعد از هر deploy حفظ شود).
5. تب **Settings** → **Networking** → **Generate Domain** → این همان آدرس عمومی ربات و وب‌پنل است (HTTPS خودکار).
6. Deploy بزن. لاگ‌ها باید `Run polling for bot ...` و `وب‌پنل ادمین روی پورت ...` را نشان دهند.

> ⚠️ `PROXY_URL` را روی Railway تنظیم نکن — فقط برای لپ‌تاپ داخل ایران لازم است.

## 📲 انتقال داده‌های فعلی به Railway (Import/Export)

1. در ربات فعلی (لپ‌تاپ): `/export` → دو فایل دانلود کن (`bot-db-*.db` و `env-*.txt`).
2. روی Railway بعد از deploy: `/import` بزن و فایل دیتابیس را بفرست → تأیید کن.
3. ری‌استارت سرویس در Railway (Deploy → Restart). تمام — کاربران، پنل‌ها، پلن‌ها و سفارش‌ها منتقل شدند.
4. ⚠️ فقط **یک نمونه** از ربات (لپ‌تاپ یا Railway) باید فعال باشد؛ دو نمونه با یک توکن خطای Conflict می‌دهند.

## 🔌 اتصال پنل‌ها (3x-ui / Marzban)

راهنمای کامل و تصویری هر فیلد: [PANELS_GUIDE.md](PANELS_GUIDE.md)
- خلاصه 3x-ui: Base URL با پورت + یوزر/پس ادمین + Inbound ID از تب Inbounds + آدرس Subscription (Panel Settings → Subscription)
- خلاصه Marzban: Base URL داشبورد + یوزر/پس ادمین + مقدار `XRAY_SUBSCRIPTION_URL_PREFIX`

## 🛠 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `TelegramNetworkError` روی لپ‌تاپ ایران | `PROXY_URL=socks5://127.0.0.1:10808` (پورت v2rayN) و مطمئن شو فیلترشکن روشن است |
| `Conflict: terminated by other getUpdates request` | دو نمونه ربات با یک توکن اجراست — یکی را خاموش کن |
| وب‌پنل بالا نمی‌آید | `ADMIN_WEB_PASSWORD` خالی است (لاگ هشدار می‌دهد) یا `ADMIN_WEB_ENABLED=1` نگذاشته‌ای |
| «هیچ پنلی در دسترس نبود» موقع تأیید | از `/panels` یا وب‌پنل، تست اتصال بزن؛ یوزر/پس یا آدرس را اصلاح کن |
| لینک اشتراک باز نمی‌شود | `sub_base_url` پنل را اشتباه گذاشته‌ای — PANELS_GUIDE.md بخش Subscription |
| جایزه رفرال صادر نشد | لاگ را ببین؛ معمولاً پنل در دسترس نبوده. بعد از رفع، دستی از طریق ساخت سفارش جبران کن |

## 🧪 تست سریع بعد از نصب

1. در تلگرام `/start` بزن → منوی فارسی می‌آید
2. «🛒 خرید اشتراک» → یک حجم و مدت انتخاب کن → شماره کارت نمایش داده می‌شود
3. یک متن به‌جای رسید بفرست → پیام به ادمین می‌رسد با دکمه ✅/❌
4. تأیید کن → لینک اشتراک تحویل می‌شود (اگر پنل متصل باشد)
5. وب‌پنل را باز کن → سفارش تحویل‌شده را در تب سفارش‌ها ببین
6. `/export` بزن → فایل پشتیبان دریافت می‌شود
